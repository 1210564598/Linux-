## 指针声明练习题答案表

| 题号 | 题目要求                                                     | 声明语句                      | 含义拆解                                          |
| :--- | :----------------------------------------------------------- | :---------------------------- | :------------------------------------------------ |
| 1    | 一个整形数                                                   | `int a;`                      | 普通的整型变量                                    |
| 2    | 一个指向整形数的指针                                         | `int *p;`                     | p 是指针，指向 int 类型                           |
| 3    | 一个指向指针的指针，它指向的指针指向一个整形数               | `int **pp;`                   | pp 是二级指针，指向 int* 类型                     |
| 4    | 一个有10个整形数的数组                                       | `int arr[10];`                | arr 是数组，有10个 int 元素                       |
| 5    | 一个有10个指针的数组，每个指针指向一个整形数                 | `int *p[10];`                 | p 是数组，有10个 int* 元素                        |
| 6    | 一个有10个整形数的数组的指针                                 | `int (*p)[10];`               | p 是指针，指向 int[10] 数组                       |
| 7    | 一个指向指针的指针，被指向的指针指向一个有10个整形数的数组   | `int *(*pp)[10];`             | pp 是指针，指向 int*[10] 类型                     |
| 8    | 一个指向数组的指针，该数组有10个整形数                       | `int (*p)[10];`               | 同第6题                                           |
| 9    | 一个指向函数的指针，该函数有一个整形数并返回一个整形数       | `int (*p)(int);`              | p 是函数指针，参数 int，返回 int                  |
| 10   | 一个有10个指针的数组，每个指针指向一个函数，该函数有一个整形数并返回一个整形数 | `int (*p[10])(int);`          | p 是数组，元素是函数指针                          |
| 11   | 一个函数的指针，指向的函数的类型是有两个整形数并且返回一个函数指针的函数，返回的函数指针指向一个有整形数且返回整形数的函数 | `int (*(*p)(int, int))(int);` | p 是函数指针，参数(int,int)，返回值是 int(*)(int) |

## 记忆技巧表

| 模式                   | 写法                         | 说明                   |
| :--------------------- | :--------------------------- | :--------------------- |
| 普通指针               | `int *p`                     | 星号在变量名前         |
| 二级指针               | `int **pp`                   | 两个星号               |
| 指针数组（数组存指针） | `int *p[10]`                 | 先写数组名和方括号     |
| 数组指针（指向数组）   | `int (*p)[10]`               | 先写指针，括号包住     |
| 函数指针               | `int (*p)(int)`              | 括号包住星号和函数名   |
| 函数指针数组           | `int (*p[10])(int)`          | 数组+函数指针的结合    |
| 复杂函数指针           | `int (*(*p)(int, int))(int)` | 层层拆解，从最外层开始 |

## 优先级口诀

> **后缀括号 [ ] 和 ( ) 优先于前缀星号 ***
>
> - 不加括号：`int *p[10]` → 先数组后指针（指针数组）
> - 加括号：`int (*p)[10]` → 先指针后数组（数组指针）

| 优先级   | 写法     | 结合顺序         |
| :------- | :------- | :--------------- |
| 高       | `p[10]`  | 先数组           |
| 高       | `p(int)` | 先函数           |
| 低       | `*p`     | 后指针           |
| 改变顺序 | `(*p)`   | 括号强制指针优先 |
