# 146-DashBoadFinish 开发文档

---

## 一、架构总览

你要做的是一个汽车仪表盘——纯手绘的速度表动画。窗口固定 800×600，黑底，表盘从 0 到 240 Km/h，指针来回摆动。

运行时效果：

```
┌─────────────────────────────────────┐
│                 240                  │
│             200     20               │
│         160             40           │
│     ●═══●═══●═══●═══●═══●═══●     │
│   ●                       ●         │
│   ●          180          ●         │
│   ●         Km/h          ● 红色区域│
│   ●                       ●         │
│     ●                   ●  (40以上) │
│         ●           ●              │
│             ●     ●                 │
│          [汽车logo图标]              │
└─────────────────────────────────────┘
```

**这个项目跟 TCP 完全无关——不需要网络模块。** 整个界面只有一个 QWidget，没有放任何子控件，全部画面通过 `paintEvent` 里的 `QPainter` 手绘出来。

**整体结构：**

```
Widget 窗口 (800×600)
  │
  ├── QTimer *timer        ← 50ms 定时器，驱动动画
  ├── int currentValue     ← 当前指针位置 (0-61)
  ├── int mark             ← 方向标记 (0=加速, 1=减速)
  ├── int startAngle       ← 表盘起始角度 = 150°
  ├── double angle         ← 每个刻度的度数 = 240°/60 = 4°
  │
  └── paintEvent()         ← 每帧用 QPainter 画一遍
        ├── initCanvas()          黑底 + 坐标原点移到表盘中心
        ├── drawMiddleCircle()    中心小圆
        ├── drawScale()           60 个刻度线
        ├── drawScaleText()       刻度数字 (0,20,40...240)
        ├── drawPointLine()       速度指针 (多边形)
        ├── drawSpeedPie()        红色扇形填充
        ├── drawEllipseInnerShine() 内圈红色光晕
        ├── drawEllipseInnerBlack() 中心黑色遮罩圆
        ├── drawCurrentSpeed()    当前速度数字 + Km/h
        ├── drawEllipseOutterShine() 外环红色发光
        └── drawLogo()            汽车 logo 图标
```

**动画驱动：**

```
QTimer::timeout (每 50ms)
    │
    ├── currentValue++ (加速) 或 currentValue-- (减速)
    ├── currentValue 在 0~61 之间来回摆动
    └── update() → 触发 paintEvent() → 重绘整个表盘
```

**开发顺序：** 项目框架 → 资源文件 → 界面 → 头文件 → 实现代码。下面一步步来。

### 步骤 4：写头文件

打开 `widget.h`，替换为以下完整代码：

```cpp
#ifndef WIDGET_H
#define WIDGET_H

#include <QWidget>

QT_BEGIN_NAMESPACE
namespace Ui { class Widget; }
QT_END_NAMESPACE

class Widget : public QWidget
{
    Q_OBJECT

public:
    Widget(QWidget *parent = nullptr);
    ~Widget();

protected:
    void paintEvent(QPaintEvent *event) override;   // 重写：所有画面在这里画

private:
    Ui::Widget *ui;
    QTimer *timer;           // 动画驱动定时器
    int currentValue;        // 当前指针位置 (0-61)
    int mark = 0;            // 0=加速 1=减速
    int startAngle;          // 表盘起始角度 = 150°
    double angle;            // 每个刻度角度 = 4°

    // 下面是各个绘图函数，每个负责画表盘的一部分
    void initCanvas(QPainter& painter);
    void drawMiddleCircle(QPainter& painter,int radius);
    void drawCurrentSpeed(QPainter& painter);
    void drawScale(QPainter& painter,int radius);
    void drawScaleText(QPainter& painter,int radius);
    void drawPointLine(QPainter &painter,int lenth);
    void drawSpeedPie(QPainter& painter,int radius);
    void startSpeed();       // 启动动画
    void drawEllipseInnerBlack(QPainter& painter,int radius);
    void drawEllipseInnerShine(QPainter& painter,int radius);
    void drawEllipseOutterShine(QPainter& painter,int radius);
    void drawLogo(QPainter& painter,int radius);
};
#endif // WIDGET_H
```

**每个成员是干什么的：**

| 成员 | 为什么需要它 |
|------|-------------|
| `QTimer *timer` | 每 50ms 触发一次，更新 `currentValue` 后重绘 |
| `currentValue` | 0-61，乘以 4 就是显示的速度（0-244 Km/h） |
| `mark` | 方向标记。0 表示指针在往右加速，1 表示往左减速。到边界切换 |
| `startAngle = 150` | 表盘从 150° 开始（3 点钟方向为 0°，150° ≈ 左下方） |
| `angle = 4.0` | 240° 弧 / 60 格 = 每格 4° |
| `paintEvent()` | Qt 每次刷新窗口时调用，所有绘图在这一个函数里 |

### 步骤 5：写实现代码

打开 `widget.cpp`，替换为以下**完整文件**：

```cpp
#include "widget.h"
#include "ui_widget.h"

#include <QPainter>
#include <QDebug>
#include <QTimer>
#include <QtMath>

Widget::Widget(QWidget *parent)
    : QWidget(parent)
    , ui(new Ui::Widget)
{
    ui->setupUi(this);
    setFixedSize(800,600);
    startAngle = 150;
    startSpeed();
}

Widget::~Widget()
{
    delete ui;
}

void Widget::initCanvas(QPainter& painter)
{
    painter.setRenderHint(QPainter::Antialiasing,true);

    //底色弄成黑色
    painter.setBrush(Qt::black);
    painter.drawRect(rect());

    //坐标系 平移到中心
    QPoint cent(rect().width()/2, rect().height()*0.6);
    painter.translate(cent);
}

void Widget::drawMiddleCircle(QPainter &painter, int radius)
{
    // 画小圆
    painter.setPen(QPen(Qt::white,3));
    painter.drawEllipse(QPoint(0,0),radius,radius);
}

void Widget::drawCurrentSpeed(QPainter &painter)
{
    //当前值
    painter.setPen(Qt::white);
    QFont font("Arial",30);
    font.setBold(true);
    painter.setFont(font);
    // painter.drawText(0,0,QString::number(currentValue));
    painter.drawText(QRect(-60,-60,120,70),Qt::AlignCenter,QString::number(currentValue*4));

    QFont font2("Arial",13);
    font.setBold(true);
    painter.setFont(font2);
    painter.drawText(QRect(-60,-60,120,160),Qt::AlignCenter,"Km/h");
}

void Widget::drawScale(QPainter &painter, int radius)
{
    //画刻度
    //1. 算出一个刻度需要旋转的角度
    angle = 240*1.0 / 60;//270*1.0的作用是扩大变量类型，把int型阔成double,保留小数
    //保存当前坐标位置，此时此刻是在原点，x在3点钟方向
    painter.save();
    painter.setPen(QPen(Qt::white,5));
    //2.  设置第一个刻度的位置
    painter.rotate(startAngle);
    for(int i=0;i<=60;i++){
        if( i >= 40){
            painter.setPen(QPen(Qt::red,5));
        }
        if(i % 5 == 0){
            //画长的刻度线
            painter.drawLine(radius - 20, 0, radius - 3 ,0);
        }else{//画短的刻度线
            painter.drawLine(radius - 8, 0, radius - 3 ,0);
        }
        //画完后旋转
        painter.rotate(angle);
    }
    painter.restore();
    painter.setPen(QPen(Qt::white,5));
}

void Widget::drawScaleText(QPainter &painter, int radius)
{
    //写刻度文字
    QFont font("Arial",15);
    font.setBold(true);
    painter.setFont(font);
    int r = radius - 49;
    for(int i=0; i<=60; i++){
        if(i % 5 == 0){
            //保存坐标系
            painter.save();
            //算出平移点，弧度=角度*3.1415/180
            int delX = qCos( (210-angle*i)*M_PI/180) * r;//QT中sin认的是弧度
            int delY = qSin(qDegreesToRadians(210-angle*i)) * r;
            //平移坐标系
            painter.translate(QPoint(delX,-delY));
            //旋转坐标系
            painter.rotate(-120+angle*i);//angle=4,30*4=120的时候，实参是0，120
            //写上文字
            painter.drawText(-25,-25,50,30,Qt::AlignCenter,QString::number(i*4));
            //恢复坐标系
            painter.restore();
        }
    }
}

void Widget::drawPointLine(QPainter &painter,int lenth)
{
    //画指针，线

    painter.save();


    painter.setBrush(Qt::white);
    painter.setPen(Qt::NoPen);
    static const QPointF points[4] = {
        QPointF(0,0.0),
        QPointF(200.0,-1.1),
        QPointF(200.0,1.1),
        QPointF(0,15.0),

    };


    painter.rotate(startAngle + angle * currentValue);
    painter.drawPolygon(points, 4);
    // painter.drawLine(60,0,lenth,0);
    //坐标轴先回到原点
    painter.restore();
}

void Widget::drawSpeedPie(QPainter &painter, int radius)
{

    QRect rentangle(-radius,-radius,radius*2,radius*2);
    painter.setPen(Qt::NoPen);
    painter.setBrush(QColor(255,0,0,80));
    painter.drawPie(rentangle,(360-startAngle)*16,-angle*currentValue*16);//angle前面取 负数，为了让它顺时针方向画
}

void Widget::startSpeed()
{
    timer = new QTimer(this);

    currentValue = 0;
    connect(timer, &QTimer::timeout,[=](){
        if(mark == 0){
            currentValue++;
            if(currentValue >= 61){
                mark = 1;
            }

        }
        if(mark == 1){
            currentValue--;
            if(currentValue == 0){
                mark = 0;
            }
        }

        update();
    });
    timer->start(50);
}

void Widget::drawEllipseInnerBlack(QPainter &painter, int radius)
{
    painter.setBrush(Qt::black);
    painter.drawEllipse(QPoint(0,0),radius,radius);
}

void Widget::drawEllipseInnerShine(QPainter &painter, int radius)
{
    QRadialGradient radialGradient(0,0,radius);
    radialGradient.setColorAt(0.0, QColor(255,0,0,200)); // 中心颜色
    radialGradient.setColorAt(1.0, QColor(0,0,0,100));  // 外围颜色
    painter.setBrush(radialGradient);
    painter.drawEllipse(QPoint(0,0),radius,radius);
}

void Widget::drawEllipseOutterShine(QPainter &painter, int radius)
{

    QRect rentangle(-radius,-radius,radius*2,radius*2);
    painter.setPen(Qt::NoPen);

    QRadialGradient radiaGradient(0,0,radius);
    radiaGradient.setColorAt(1,QColor(255,0,0,200));
    radiaGradient.setColorAt(0.97,QColor(255,0,0,120));
    radiaGradient.setColorAt(0.9,QColor(0,0,0,0));
    radiaGradient.setColorAt(0,QColor(0,0,0,0));
    painter.setBrush(radiaGradient);

    painter.drawPie(rentangle,(360-150)*16,-angle*61*16);//angle前面取 负数，为了让它顺时针方向画
}

void Widget::drawLogo(QPainter &painter, int radius)
{
    QRect rectangle(-65,radius*0.38,130,50);
    painter.drawPixmap(rectangle,QPixmap(":/icon.png"));
}

void Widget::paintEvent(QPaintEvent *event)
{
    QPainter painter(this);
    int rad = height()/2;
    //初始化画布
    initCanvas(painter);
    //画小圆
    drawMiddleCircle(painter,60);
    //画刻度
    drawScale(painter, rad);
    //画刻度文字
    drawScaleText(painter, rad);
    //指针
    drawPointLine(painter, rad-58);
    //画扇形
    drawSpeedPie(painter, rad+25);
    //画渐变内圈圆
    drawEllipseInnerShine(painter,110);
    //画黑色内圈
    drawEllipseInnerBlack(painter, 80);
    //画当前速度
    drawCurrentSpeed(painter);
    //画外环发光圈
    drawEllipseOutterShine(painter,rad+25);
    //画一个汽车logo
    drawLogo(painter, rad);
}
```

## 三、代码逐段说明

### 构造函数

```cpp
setFixedSize(800,600);     // 固定窗口大小，不让用户拖拽
startAngle = 150;           // 表盘从 150° 开始（3 点钟方向算 0°）
startSpeed();               // 启动动画
```

### initCanvas() —— 黑底 + 坐标原点移到中心

```cpp
painter.setRenderHint(QPainter::Antialiasing, true);  // 开启抗锯齿
painter.setBrush(Qt::black);
painter.drawRect(rect());    // 用黑色填满整个窗口

QPoint cent(400, 360);       // 水平居中，垂直偏下（0.6 = 360/600）
painter.translate(cent);     // 把坐标原点移到 (400, 360)
```

**为什么要 translate：** 后续所有绘图都相对于表盘中心操作，画圆、旋转、画刻度都简单很多——圆心就是 `(0, 0)`。

### drawScale() —— 画 60 个刻度线

```cpp
angle = 240.0 / 60;          // 表盘弧长 240°，60 格，每格 4°
painter.save();              // 记录初始状态
painter.rotate(startAngle);  // 旋转到 150°（第一个刻度的位置）

for(int i = 0; i <= 60; i++){
    if(i >= 40) painter.setPen(...red...);  // 40 格以后（即 160 Km/h 以上）变红

    if(i % 5 == 0)
        painter.drawLine(radius-20, 0, radius-3, 0);  // 长线（每 5 格）
    else
        painter.drawLine(radius-8, 0, radius-3, 0);  // 短线

    painter.rotate(angle);    // 转 4° 画下一根
}
painter.restore();
```

**关键技巧：** `painter.rotate()` 之后坐标系方向变了。"向右画线"就是在当前角度方向画线。循环里不需要自己算三角函数——转了再画就行。

### drawScaleText() —— 写刻度数字（0, 20, 40...240）

```cpp
int r = radius - 49;   // 文字离圆心再近 49px

for(int i = 0; i <= 60; i++){
    if(i % 5 == 0){    // 每 5 格写一个字
        painter.save();

        // 用三角函数算出文字位置
        int delX = qCos((210 - angle*i) * M_PI/180) * r;
        int delY = qSin(qDegreesToRadians(210 - angle*i)) * r;
        painter.translate(delX, -delY);

        // 旋转文字让它正着显示
        painter.rotate(-120 + angle*i);

        painter.drawText(-25, -25, 50, 30, Qt::AlignCenter, QString::number(i*4));
        painter.restore();
    }
}
```

**为什么 dely 取负号：** Qt 的 Y 轴向下是正方向，但 `qSin` 算出来的是数学坐标（上正下负）。取负号纠正。

### drawPointLine() —— 画速度指针

```cpp
static const QPointF points[4] = {
    QPointF(0, 0.0),       // 针尖（在圆心）
    QPointF(200.0, -1.1),  // 指针上沿
    QPointF(200.0, 1.1),   // 指针下沿
    QPointF(0, 15.0),       // 底部宽座
};

painter.rotate(startAngle + angle * currentValue);  // 根据当前速度旋转
painter.drawPolygon(points, 4);                      // 用 4 个点画一个楔形
```

**指针是一个 4 个点的多边形，不是一条线。** 这样画出来有宽度变化——前端尖、后端宽，更像真实仪表盘的指针。

### drawSpeedPie() —— 红色扇形填充

```cpp
painter.drawPie(rectangle,
    (360 - startAngle) * 16,        // 起始角 (Qt 用 1/16 度单位)
    -angle * currentValue * 16);    // 跨度 (负 = 顺时针)
```

`drawPie` 的参数单位是 **1/16 度**（`* 16`），取负数表示顺时针方向。

### startSpeed() —— 动画核心

```cpp
timer = new QTimer(this);
currentValue = 0;

connect(timer, &QTimer::timeout, [=](){
    if(mark == 0){              // 加速中
        currentValue++;
        if(currentValue >= 61) mark = 1;   // 到头了，开始减速
    }
    if(mark == 1){              // 减速中
        currentValue--;
        if(currentValue == 0) mark = 0;    // 归零了，开始加速
    }
    update();    // 触发重绘
});
timer->start(50);   // 每 50ms 一帧 = 20 FPS
```

**动画逻辑：**
```
0 ──加速──► 61 ──减速──► 0 ──加速──► 61 ... 无限循环
```

### drawEllipseInnerShine() —— 内圈红色光晕

```cpp
QRadialGradient radialGradient(0, 0, radius);
radialGradient.setColorAt(0.0, QColor(255, 0, 0, 200));  // 圆心：不透明红
radialGradient.setColorAt(1.0, QColor(0, 0, 0, 100));     // 边缘：半透明黑
painter.setBrush(radialGradient);
painter.drawEllipse(QPoint(0,0), radius, radius);
```

用径向渐变制造发光效果——圆心最亮、边缘渐暗。

### drawEllipseOutterShine() —— 外环发光圈

和 `drawSpeedPie` 一样是扇形，但用了径向渐变做画刷，形成外圈亮红→内圈透明的光晕。渐变只有边缘两圈有红色，其余透明。

### drawEllipseInnerBlack() —— 中心遮罩

纯黑色实心圆，覆盖表盘中心区域。因为刻度线和扇形都画到圆心了，用这个黑色圆把中间盖掉，给速度数字提供干净背景。

### drawLogo() —— 画汽车图标

```cpp
QRect rectangle(-65, radius*0.38, 130, 50);
painter.drawPixmap(rectangle, QPixmap(":/icon.png"));
```

从资源文件中加载 icon.png，画在表盘下方的中心位置。`:/` 前缀表示 Qt 资源系统。

### paintEvent() —— 总调度

```cpp
void Widget::paintEvent(QPaintEvent *event)
{
    QPainter painter(this);
    int rad = height() / 2;          // 半径 = 300

    initCanvas(painter);              // 1. 黑底 + 坐标移到中心
    drawMiddleCircle(painter, 60);    // 2. 画中心白圆
    drawScale(painter, rad);          // 3. 画刻度线
    drawScaleText(painter, rad);      // 4. 写刻度数字
    drawPointLine(painter, rad-58);  // 5. 画指针
    drawSpeedPie(painter, rad+25);   // 6. 红色扇形
    drawEllipseInnerShine(painter, 110);  // 7. 内圈光晕
    drawEllipseInnerBlack(painter, 80);   // 8. 中心遮罩
    drawCurrentSpeed(painter);        // 9. 速度数字
    drawEllipseOutterShine(painter, rad+25); // 10. 外环发光
    drawLogo(painter, rad);           // 11. 汽车图标
}
```

**绘制顺序很重要：** 先画的在底层，后画的在上层。所以遮罩圆在速度文字之前画，发光在最后画。

## 四、关键技术点

### 坐标系变换（translate + rotate + save/restore）

这是整个项目的核心技巧。每次画之前：

1. `translate(圆心)` —— 把原点移到表盘中心
2. `rotate(角度)` —— 旋转坐标系到当前位置
3. 直接在旋转后的坐标系里画——不用算三角函数
4. `save()` + `restore()` —— 画完恢复，不影响后面的绘图

### QTimer lambda 连接

```cpp
connect(timer, &QTimer::timeout, [=](){
    // lambda 里直接访问 currentValue, mark
});
```

不用声明槽函数，直接在 lambda 里写逻辑。`[=]` 按值捕获所有局部变量。

### drawPie 角度单位

Qt 的 `drawPie` 角度单位是 1/16 度：
- `360° × 16 = 5760`
- `-angle * currentValue * 16`，负号表示顺时针

### 抗锯齿

```cpp
painter.setRenderHint(QPainter::Antialiasing, true);
```

没有这行，圆的边缘会全是锯齿。必须在 `paintEvent` 最开始设置。
