### initCanvas() —— 初始化画布

```cpp
void Widget::initCanvas(QPainter& painter)
{
    painter.setRenderHint(QPainter::Antialiasing, true);   // ①

    painter.setBrush(Qt::black);                            // ②
    painter.drawRect(rect());                               // ③

    QPoint cent(rect().width()/2, rect().height()*0.6);     // ④
    painter.translate(cent);                                // ⑤
}
```

| 编号 | 函数 | 说明 |
|:----:|------|------|
| ① | `QPainter::setRenderHint(Antialiasing, true)` | 开启抗锯齿。没有这行，画出来的圆和斜线全是锯齿。必须在 `paintEvent` 最开始调用 |
| ② | `QPainter::setBrush(QBrush)` | 设置填充画刷。`Qt::black` 是黑色实心画刷 |
| ③ | `QPainter::drawRect(QRect)` | 用当前画刷填充一个矩形。这里填充整个窗口区域 = 全黑背景 |
| ④ | `QWidget::rect()` | 获取 Widget 的矩形范围。`width()=800`, `height()=600` |
| ⑤ | `QPainter::translate(QPoint)` | **把坐标原点移到 (400, 360)**。这样圆心就是 (0,0)，后续所有绘图都围绕这个点 |

**为什么坐标系原点设在 (400, 360)：** 水平居中，垂直在 60% 处——表盘上面有空间显示数字，下面有空间放 logo。

### drawScale() —— 画刻度线

```cpp
void Widget::drawScale(QPainter &painter, int radius)
{
    angle = 240*1.0 / 60;          // ①

    painter.save();                 // ②
    painter.setPen(QPen(Qt::white, 5));
    painter.rotate(startAngle);     // ③

    for(int i = 0; i <= 60; i++){
        if(i >= 40){
            painter.setPen(QPen(Qt::red, 5));   // ④
        }
        if(i % 5 == 0){
            painter.drawLine(radius-20, 0, radius-3, 0);  // ⑤ 长线
        }else{
            painter.drawLine(radius-8, 0, radius-3, 0);   // ⑥ 短线
        }
        painter.rotate(angle);      // ⑦
    }
    painter.restore();              // ⑧
    painter.setPen(QPen(Qt::white, 5));
}
```

| 编号 | 函数 | 说明 |
|:----:|------|------|
| ① | `240*1.0 / 60` | 表盘弧长 240°，60 个刻度，每个 4°。`*1.0` 把 int 转 double 保留小数 |
| ② | `QPainter::save()` | **保存当前坐标状态**（位置 + 旋转 + 画笔），之后 `restore()` 可以还原 |
| ③ | `QPainter::rotate(degrees)` | 旋转坐标系 150°。现在 Y 轴正方向指向第一个刻度的位置 |
| ④ | `setPen(QPen(Qt::red, 5))` | 第 40 格以后（160 Km/h 以上），刻度线变红——危险速度区间 |
| ⑤ | `QPainter::drawLine(x1,y1, x2,y2)` | 画一条线。(radius-20, 0) → (radius-3, 0)，长度 17px = 长线 |
| ⑥ | 同上 | (radius-8, 0) → (radius-3, 0)，长度 5px = 短线 |
| ⑦ | `rotate(angle)` | 转 4°，准备画下一根 |
| ⑧ | `QPainter::restore()` | **恢复**到 `save()` 时的坐标状态。后续代码不受旋转影响 |

**核心技巧：** 不是每个刻度去算画在哪里，而是画完一根 → 旋转坐标系 → 再画一根。60 根刻度用同一个逻辑跑循环。

### drawScaleText() —— 写刻度数字

```cpp
void Widget::drawScaleText(QPainter &painter, int radius)
{
    QFont font("Arial", 15);
    font.setBold(true);
    painter.setFont(font);

    int r = radius - 49;               // ①

    for(int i = 0; i <= 60; i++){
        if(i % 5 == 0){                // ②
            painter.save();

            int delX = qCos((210-angle*i) * M_PI/180) * r;    // ③
            int delY = qSin(qDegreesToRadians(210-angle*i)) * r;  // ④
            painter.translate(QPoint(delX, -delY));            // ⑤

            painter.rotate(-120 + angle*i);                    // ⑥
            painter.drawText(-25,-25,50,30,
                Qt::AlignCenter,
                QString::number(i*4));                         // ⑦
            painter.restore();
        }
    }
}
```

| 编号 | 函数 | 说明 |
|:----:|------|------|
| ① | `r = radius - 49` | 文字位置比刻度线再靠近圆心 49px |
| ② | `i % 5 == 0` | 每 5 格写一个数字，所以是 0、20、40...240 |
| ③ | `qCos(radians)` | 计算文字位置的 X 偏移。`qCos` 是 Qt 封装的 cos，参数是弧度 |
| ③ | `M_PI` | 圆周率 π，来自 `<QtMath>` |
| ④ | `qSin(radians)` / `qDegreesToRadians(deg)` | `qDegreesToRadians` 把角度转弧度，再传给 `qSin`。和上一行 `*M_PI/180` 是一个效果，两种写法 |
| ⑤ | `translate(delX, -delY)` | 把原点平移到文字的位置。**delY 取负号**：Qt Y 轴向下为正，数学坐标系 Y 轴向上为正，所以要取反 |
| ⑥ | `rotate(-120 + angle*i)` | 旋转坐标系让文字正向显示（而不是顺着表盘的弧度歪着） |
| ⑦ | `drawText(rect, align, text)` | 画文字。`i*4` = 该刻度对应的速度（0, 20, 40...240） |

**为什么起始是 210：** `startAngle=150`，第一个刻度数字 "0" 的偏转角度是 `210`。60 个数字均匀分布在 240° 弧线上。

### drawPointLine() —— 画指针

```cpp
void Widget::drawPointLine(QPainter &painter, int lenth)
{
    painter.save();

    painter.setBrush(Qt::white);          // ①
    painter.setPen(Qt::NoPen);            // ②
    static const QPointF points[4] = {    // ③
        QPointF(0, 0.0),       // 针尖（圆心）
        QPointF(200.0, -1.1),  // 指针上沿
        QPointF(200.0, 1.1),   // 指针下沿
        QPointF(0, 15.0),      // 底部宽座
    };

    painter.rotate(startAngle + angle * currentValue);  // ④
    painter.drawPolygon(points, 4);                      // ⑤

    painter.restore();
}
```

| 编号 | 函数 | 说明 |
|:----:|------|------|
| ① | `QPainter::setBrush(Qt::white)` | 多边形填充为白色 |
| ② | `QPainter::setPen(Qt::NoPen)` | 不画边框线——纯填充。有边框线指针边缘会多一圈细线 |
| ③ | `QPointF(x, y)` | 浮点坐标。定义了一个 4 个点的楔形（针尖 → 细杆 → 宽底） |
| ③ | `static const` | 静态常量——这个多边形形状不会变，只创建一次，省性能 |
| ④ | `rotate(startAngle + angle * currentValue)` | 旋转到当前速度对应的角度。`startAngle=150` 是 0 速的位置，`angle*currentValue` 是当前偏移 |
| ⑤ | `QPainter::drawPolygon(points, count)` | 按顺序连接 4 个点，填充封闭图形 |

**为什么用多边形而不是画线：** 4 点楔形有宽度变化（尖端细、底部宽），更像真实仪表盘指针。一条线没有厚度，视觉效果差。

### drawSpeedPie() —— 速度累积扇形

```cpp
void Widget::drawSpeedPie(QPainter &painter, int radius)
{
    QRect rentangle(-radius, -radius, radius*2, radius*2);   // ①
    painter.setPen(Qt::NoPen);
    painter.setBrush(QColor(255, 0, 0, 80));                  // ②
    painter.drawPie(rentangle,
        (360-startAngle)*16,           // ③ 起始角
        -angle*currentValue*16);       // ④ 跨度（负=顺时针）
}
```

| 编号 | 函数 | 说明 |
|:----:|------|------|
| ① | `QRect(x, y, w, h)` | 扇形所在的外接矩形。圆心在原点，把矩形左上角设为 (-r, -r) |
| ② | `QColor(r, g, b, a)` | 半透明红色。a=80 ≈ 31% 不透明度，可以看到底下的刻度线 |
| ③ | `drawPie(rect, startAngle, spanAngle)` | 画扇形。`(360-150)*16 = 210*16` 是起始角 |
| ④ | `-angle*currentValue*16` | 跨度。**负号 = 顺时针**（Qt 默认逆时针）。**×16**：Qt 的 drawPie 角度单位是 1/16 度 |

**Qt drawPie 角度单位说明：** `360° × 16 = 5760` 才是一整圈。所有给 drawPie 的角度参数必须 ×16。

### startSpeed() —— 动画定时器

```cpp
void Widget::startSpeed()
{
    timer = new QTimer(this);          // ①

    currentValue = 0;
    connect(timer, &QTimer::timeout, [=](){   // ②
        if(mark == 0){
            currentValue++;
            if(currentValue >= 61){
                mark = 1;              // ③ 到顶了，换方向
            }
        }
        if(mark == 1){
            currentValue--;
            if(currentValue == 0){
                mark = 0;              // ④ 到底了，换方向
            }
        }
        update();                      // ⑤
    });
    timer->start(50);                  // ⑥
}
```

| 编号 | 函数 | 说明 |
|:----:|------|------|
| ① | `new QTimer(this)` | 创建定时器。`this` 为父对象，Widget 销毁时自动释放 |
| ② | `connect(timer, &QTimer::timeout, [=]{...})` | **lambda 连接**：不需要声明单独的槽函数，直接在 connect 里写逻辑 |
| ② | `[=]` | 按值捕获外部变量（currentValue, mark 等）。lambda 内可以直接修改 |
| ③ | `mark = 1` | 方向从加速切换到减速 |
| ④ | `mark = 0` | 方向从减速切换回加速 |
| ⑤ | `QWidget::update()` | **触发重绘**。Qt 在下一次事件循环中调用 `paintEvent()` |
| ⑥ | `QTimer::start(ms)` | 每 50 毫秒触发一次 timeout。50ms = 20 帧/秒 |

**动画逻辑：**
```
currentValue: 0 → 1 → 2 → ... → 60 → 61
               ↑                         ↓
               ← ← ← ← ← ← ← ← ← ← ← ← ←
```
显示速度 = currentValue × 4，即 0 → 244 → 0 → 244 ...

### drawEllipseOutterShine() —— 外环发光圈

```cpp
void Widget::drawEllipseOutterShine(QPainter &painter, int radius)
{
    QRect rentangle(-radius, -radius, radius*2, radius*2);
    painter.setPen(Qt::NoPen);

    QRadialGradient radiaGradient(0, 0, radius);
    radiaGradient.setColorAt(1, QColor(255,0,0,200));    // 外缘：亮红
    radiaGradient.setColorAt(0.97, QColor(255,0,0,120));  // 稍内：半透明红
    radiaGradient.setColorAt(0.9, QColor(0,0,0,0));       // 内层：完全透明
    radiaGradient.setColorAt(0, QColor(0,0,0,0));         // 圆心：完全透明
    painter.setBrush(radiaGradient);

    painter.drawPie(rentangle,
        (360-150)*16,       // 起始角
        -angle*61*16);      // 完整的 240° 弧
}
```

**技术要点：**
- 渐变只在外圈很薄的一层有红色（位置 0.97~1.0），内层全部透明
- `drawPie` 画的是扇形不是整圆，所以光晕只出现在有刻度的 240° 弧段上
- 扇形的跨度是 `angle*61*16`，覆盖全部 61 个刻度点

### paintEvent() —— 每一帧的总调度

```cpp
void Widget::paintEvent(QPaintEvent *event)
{
    QPainter painter(this);           // ①
    int rad = height()/2;             // ②

    initCanvas(painter);              // ③ 先后顺序决定前后遮挡关系
    drawMiddleCircle(painter, 60);
    drawScale(painter, rad);
    drawScaleText(painter, rad);
    drawPointLine(painter, rad-58);
    drawSpeedPie(painter, rad+25);
    drawEllipseInnerShine(painter, 110);
    drawEllipseInnerBlack(painter, 80);
    drawCurrentSpeed(painter);
    drawEllipseOutterShine(painter, rad+25);
    drawLogo(painter, rad);
}
```

| 编号 | 函数 | 说明 |
|:----:|------|------|
| ① | `QPainter(widget)` | 构造在指定 widget 上绘图的画笔。`this` 表示画在 Widget 自己身上 |
| ② | `rad = height()/2 = 300` | 表盘半径 = 窗口高度的一半 |
| ③ | 调用顺序 | **先画的在底层，后画的在上层。** 黑色遮罩圆必须在刻度线之后画才能盖掉中心区域 |

## 信号槽连接

整个项目只有 **一个** 信号连接，在 `startSpeed()` 中：

```cpp
connect(timer, &QTimer::timeout, [=](){
    // 更新 currentValue
    // 调用 update() 触发重绘
});
```

| 项目 | 说明 |
|------|------|
| 连接方式 | 新式 connect（函数指针）+ lambda |
| 源 | `QTimer::timeout` |
| 目标 | 匿名 lambda 函数（无命名槽） |
| 连接次数 | 一次（构造函数中调用 startSpeed） |

没有"自动连接"——因为界面上根本没有子控件按钮。所有画面都是 `paintEvent` 画的。

## 关键技术点

### 1. 坐标变换——不用算绝对坐标

```cpp
painter.translate(圆心);
painter.rotate(角度);
// 现在直接在相对坐标系里画，不用 sin/cos
painter.drawLine(100, 0, 200, 0);   // "向右画线" = 沿当前角度方向画线
painter.restore();
```

整个表盘的刻度线全是这种画法：转一次画一根，转一次画一根，60 根线不需要一次三角函数。

### 2. save/restore——局部操作不影响整体

```cpp
painter.save();      // 记住当前状态
painter.rotate(45);  // 只在这个区段内旋转
// ... 画东西 ...
painter.restore();   // 状态还原，后面的代码不受前面 rotate 影响
```

使用时 push/pop 对应——每个 `save()` 必须有一个 `restore()`。

### 3. drawPie 角度单位是 1/16 度

```cpp
painter.drawPie(rect, 210*16, -40*16);
//               起始角5760  顺时针40°
```

这不是 bug，是 Qt 为了更高精度做的设计。360° = 5760 个单位。

### 4. QRadialGradient——径向渐变

```
setColorAt(0.0)    ← 圆心
setColorAt(0.5)    ← 半径一半
setColorAt(1.0)    ← 圆周边缘
```

值必须是 0.0 ~ 1.0。圆心→边缘的每个位置可以设不同颜色和透明度，形成光晕效果。

### 5. 动画帧通过 update() → paintEvent() 循环

```
QTimer::timeout (50ms)
    │
    ├── 更新 currentValue
    └── update()
         │
         └── Qt 事件循环调用 paintEvent()
              │
              └── 全部重绘 = 新一帧
```

`update()` 不会立即重绘——它向 Qt 事件循环发一个请求，Qt 在合适的时机合并重绘。这样即使高速更新也不会重复绘制。
