# 126-TCPClientNoBug 开发文档

---

## 一、架构总览

你要做的是一个 TCP 网络调试助手客户端。运行时界面如下：

```
┌──────────────────────────────────────────┐
│  网络调试助手客户端 - 老陈出品              │
├──────────────────────────────────────────┤
│                                           │
│  ┌────────────────────────────────────┐  │
│  │  textEditRev   接收消息显示区        │  │
│  │  （红色=你发的  黑色=收到的）         │  │
│  └────────────────────────────────────┘  │
│                                           │
│  服务端IP [192.168.1.9]  端口 [8888]      │
│  [连接] [断开]                             │
│                                           │
│  ┌──────────────────────────┐ [发送]     │
│  │  textEditSend  消息输入区  │            │
│  └──────────────────────────┘            │
└──────────────────────────────────────────┘
```

程序的核心就是一个 **Widget 窗口**，里面有一个 **QTcpSocket** 负责所有网络通信。

```
┌─────────────── Widget ───────────────┐
│                                       │
│  QTcpSocket *client   ← 发数据/收数据  │
│  QTimer *timer        ← 连接超时检测  │
│                                       │
│  界面控件（由 widget.ui 生成）          │
│  ├── textEditRev      接收区          │
│  ├── lineEditIPAddr   IP输入          │
│  ├── lineEditPort     端口输入         │
│  ├── btnConnect       连接按钮         │
│  ├── btndiscon        断开按钮         │
│  ├── textEditSend     发送输入区       │
│  └── btnSend          发送按钮         │
└───────────────────────────────────────┘
```

**信号槽关系：**

```
btnConnect.clicked  ──► on_btnConnect_clicked()
    │ 里面 connectToHost() + 启动 timer
    ├── client.connected()  ──► onConnected()
    ├── client.error()      ──► onError()
    └── timer.timeout()     ──► onTimeOUt()

client.readyRead()     ──► mRead_Data_From_Server()

btnSend.clicked        ──► on_btnSend_clicked()

btndiscon.clicked      ──► on_btndiscon_clicked()
```

**开发顺序：** 先搭项目框架 → 画界面 → 写头文件声明 → 填实现代码。下面一步步来，每一步做完都会得到一个完整文件。

### 步骤 3：写头文件

打开 `widget.h`，替换为以下完整代码：

```cpp
#ifndef WIDGET_H
#define WIDGET_H

#include <QTcpSocket>      // 要用 QTcpSocket，必须包含
#include <QWidget>


QT_BEGIN_NAMESPACE
namespace Ui { class Widget; }
QT_END_NAMESPACE

class Widget : public QWidget
{
    Q_OBJECT

public:
    Widget(QWidget *parent = nullptr);
    ~Widget();

private slots:
    // 这三个是自动连接的——Qt 按命名规则 on_控件名_信号名 自动匹配
    void on_btnConnect_clicked();
    void on_btnSend_clicked();
    void on_btndiscon_clicked();

    // 这四个是手动连接的——需要在 cpp 里写 connect()
    void mRead_Data_From_Server();                       // 收到数据
    void onConnected();                                   // 连接成功
    void onError(QAbstractSocket::SocketError);           // 连接出错
    void onTimeOUt();                                     // 连接超时

private:
    Ui::Widget *ui;
    QTcpSocket *client;     // TCP 套接字——核心
    QTimer *timer;          // 连接超时定时器
    void mInserTextByColor(Qt::GlobalColor color,QString str);  // 彩色文字工具函数
};
#endif // WIDGET_H
```

**每个成员是干什么的：**

| 成员 | 为什么需要它 |
|------|-------------|
| `QTcpSocket *client` | 所有网络操作全靠它：连接服务器、发数据、收数据 |
| `QTimer *timer` | Qt 的 connectToHost 默认没有超时时间（等 OS 超时可能很久），自己加一个 5 秒定时器 |
| `mInserTextByColor()` | 让你在接收区用红色标出发送内容、黑色标出接收内容 |

### 步骤 4：写实现代码

打开 `widget.cpp`，替换为以下**完整文件**：

```cpp
#include "widget.h"
#include "ui_widget.h"

#include <QTimer>

Widget::Widget(QWidget *parent)
    : QWidget(parent)
    , ui(new Ui::Widget)
{
    ui->setupUi(this);
    this->setLayout(ui->verticalLayout);

    // 初始状态：断开和发送按钮不能用（还没连接呢）
    ui->btndiscon->setEnabled(false);
    ui->btnSend->setEnabled(false);

    // 创建 TCP 套接字，以 this 为父对象（Widget 销毁时自动释放）
    client = new QTcpSocket(this);

    // 最重要的一行：有数据到达时自动调用 mRead_Data_From_Server
    connect(client,SIGNAL(readyRead()),this,SLOT(mRead_Data_From_Server()));
}

Widget::~Widget()
{
    delete ui;
}


void Widget::on_btnConnect_clicked()
{

//    virtual void
//    connectToHost(const QHostAddress &address, quint16 port, QIODevice::OpenMode openMode = ReadWrite)
    client->connectToHost(ui->lineEditIPAddr->text(),ui->lineEditPort->text().toInt());

    timer = new QTimer(this);
    timer->setSingleShot(true);
    timer->setInterval(5000);

    connect(timer, SIGNAL(timeout()),this,SLOT(onTimeOUt()));
    connect(client,SIGNAL(connected()),this,SLOT(onConnected()));
    connect(client,SIGNAL(error(QAbstractSocket::SocketError)),
                          this,SLOT(onError(QAbstractSocket::SocketError)));

    this->setEnabled(false);
    timer->start();
}

void Widget::mRead_Data_From_Server()
{
    ui->textEditRev->moveCursor(QTextCursor::End);
    ui->textEditRev->ensureCursorVisible();
    mInserTextByColor(Qt::black,client->readAll());
}

void Widget::on_btnSend_clicked()
{
    QByteArray sendData = ui->textEditSend->toPlainText().toUtf8();
    client->write(sendData);

    mInserTextByColor(Qt::red,sendData);

}

void Widget::on_btndiscon_clicked()
{
    client->disconnectFromHost();
    client->close();
    ui->textEditRev->append("中止连接！");
    ui->btnConnect->setEnabled(true);
    ui->lineEditPort->setEnabled(true);
    ui->lineEditIPAddr->setEnabled(true);
    ui->btndiscon->setEnabled(false);
    ui->btnSend->setEnabled(false);

}

void Widget::onConnected()
{
    timer->stop();
    this->setEnabled(true);
    ui->textEditRev->append("连接成功！");
    ui->btnConnect->setEnabled(false);
    ui->lineEditPort->setEnabled(false);
    ui->lineEditIPAddr->setEnabled(false);
    ui->btndiscon->setEnabled(true);
    ui->btnSend->setEnabled(true);
}

void Widget::onError(QAbstractSocket::SocketError error)
{
    qDebug() << "连接错误：" << error;
    ui->textEditRev->insertPlainText("连接出问题啦："+client->errorString());
    this->setEnabled(true);
    on_btndiscon_clicked();
}

void Widget::onTimeOUt()
{
    ui->textEditRev->insertPlainText("连接超时");
    client->abort();
    this->setEnabled(true);
}

void Widget::mInserTextByColor(Qt::GlobalColor color,QString str)
{
    QTextCursor cursor =  ui->textEditRev->textCursor();
    QTextCharFormat format;


    format.setForeground(QBrush(QColor(color)));
    cursor.setCharFormat(format);

    cursor.insertText(str);
}
```

## 三、代码逐段说明

写完上面 5 个步骤的代码后，下面逐段讲每个函数做了什么。

### 构造函数

```cpp
ui->setupUi(this);                      // 根据 .ui 文件创建所有控件
this->setLayout(ui->verticalLayout);     // 设置顶层布局管理器

ui->btndiscon->setEnabled(false);       // 初始：断开按钮禁用
ui->btnSend->setEnabled(false);         // 初始：发送按钮禁用（未连接不能发）

client = new QTcpSocket(this);          // 创建 TCP 套接字，this 为父对象
connect(client, SIGNAL(readyRead()),    // 数据到达时自动读取
        this, SLOT(mRead_Data_From_Server()));
```

`client` 以 `this` 为父对象——Widget 销毁时自动 delete 子对象，不需要手动释放。

### on_btnConnect_clicked() —— 发起连接

```cpp
client->connectToHost(ui->lineEditIPAddr->text(),   // IP 地址
                      ui->lineEditPort->text().toInt());  // 端口

timer = new QTimer(this);
timer->setSingleShot(true);     // 只触发一次
timer->setInterval(5000);       // 5 秒超时

connect(timer, SIGNAL(timeout()), this, SLOT(onTimeOUt()));     // 超时
connect(client, SIGNAL(connected()), this, SLOT(onConnected())); // 成功
connect(client, SIGNAL(error(...)), this, SLOT(onError(...)));   // 失败

this->setEnabled(false);        // 禁用整个窗口，防用户误操作
timer->start();
```

**三种结果路径：**

```
connectToHost() ────────┬── connected()  → onConnected()  (5秒内连上了)
                        ├── error()      → onError()      (5秒内出错了)
    timer.start() ──────┴── timeout()    → onTimeOUt()    (5秒到了)
```

### onConnected() —— 连接成功

```cpp
timer->stop();                         // 取消超时计时
this->setEnabled(true);                // 恢复窗口操作
ui->textEditRev->append("连接成功！");
ui->btnConnect->setEnabled(false);     // 锁住连接按钮
ui->lineEditPort->setEnabled(false);   // 锁住端口输入
ui->lineEditIPAddr->setEnabled(false); // 锁住 IP 输入
ui->btndiscon->setEnabled(true);       // 启用断开按钮
ui->btnSend->setEnabled(true);         // 启用发送按钮
```

### onError() —— 连接失败

```cpp
qDebug() << "连接错误：" << error;
ui->textEditRev->insertPlainText("连接出问题啦：" + client->errorString());
this->setEnabled(true);
on_btndiscon_clicked();    // 复用断开逻辑清理状态
```

### onTimeOUt() —— 连接超时

```cpp
ui->textEditRev->insertPlainText("连接超时");
client->abort();    // abort 立即中止，不等服务器确认
this->setEnabled(true);
```

### on_btnSend_clicked() —— 发送数据

```cpp
QByteArray sendData = ui->textEditSend->toPlainText().toUtf8();
client->write(sendData);
mInserTextByColor(Qt::red, sendData);    // 红色回显 = 发出的
```

### mRead_Data_From_Server() —— 接收数据

```cpp
ui->textEditRev->moveCursor(QTextCursor::End);   // 光标移到底部
ui->textEditRev->ensureCursorVisible();           // 自动滚动
mInserTextByColor(Qt::black, client->readAll());  // 黑色 = 收到的
```

### on_btndiscon_clicked() —— 断开连接

```cpp
client->disconnectFromHost();    // 优雅断开：发 FIN 包
client->close();                 // 关闭本地套接字
ui->textEditRev->append("中止连接！");
// 恢复初始按钮状态……
```

### mInserTextByColor() —— 彩色文字

```cpp
QTextCursor cursor = ui->textEditRev->textCursor();  // 获取光标
QTextCharFormat format;
format.setForeground(QBrush(QColor(color)));          // 设前景色
cursor.setCharFormat(format);                         // 应用格式
cursor.insertText(str);                               // 插入文字
```

三步：取光标 → 设颜色 → 插入文字。

## 四、UI 状态说明

| 状态 | 连接按钮 | 断开按钮 | 发送按钮 | IP/端口输入 | 什么时候 |
|------|:---:|:---:|:---:|:---:|------|
| 未连接 | ✅ | ❌ | ❌ | 可改 | 程序刚启动 / 断连后 |
| 连接中 | ❌ | ❌ | ❌ | 不可改 | 点了连接后到结果出来前 |
| 已连接 | ❌ | ✅ | ✅ | 不可改 | connected() 触发后 |

## 五、用到的 Qt API

| API | 所属类 | 在哪里用 | 干什么 |
|-----|--------|---------|--------|
| `connectToHost(host, port)` | QTcpSocket | on_btnConnect_clicked | 连接服务器 |
| `readAll()` | QTcpSocket | mRead_Data_From_Server | 读取收到的数据 |
| `write(QByteArray)` | QTcpSocket | on_btnSend_clicked | 发送数据 |
| `disconnectFromHost()` | QTcpSocket | on_btndiscon_clicked | 优雅断开 |
| `close()` | QTcpSocket | on_btndiscon_clicked | 关闭套接字 |
| `abort()` | QTcpSocket | onTimeOUt | 强制中止 |
| `errorString()` | QTcpSocket | onError | 获取错误描述 |
| `connected()` 信号 | QTcpSocket | on_btnConnect_clicked | 连接成功通知 |
| `readyRead()` 信号 | QTcpSocket | 构造函数 | 数据到达通知 |
| `error(SocketError)` 信号 | QTcpSocket | on_btnConnect_clicked | 连接失败通知 |
| `setSingleShot(true)` | QTimer | on_btnConnect_clicked | 定时器只触发一次 |
| `setInterval(ms)` | QTimer | on_btnConnect_clicked | 设置超时间隔 |
| `start()` / `stop()` | QTimer | on_btnConnect_clicked / onConnected | 启动/停止定时器 |
| `timeout()` 信号 | QTimer | on_btnConnect_clicked | 定时器到点通知 |
| `toPlainText()` | QTextEdit | on_btnSend_clicked | 获取输入文字 |
| `append(str)` | QTextEdit | onConnected | 追加一行文字 |
| `insertPlainText(str)` | QTextEdit | onError | 在光标处插入文字 |
| `moveCursor(End)` | QTextEdit | mRead_Data_From_Server | 光标移到底部 |
| `ensureCursorVisible()` | QTextEdit | mRead_Data_From_Server | 自动滚动 |
| `textCursor()` | QTextEdit | mInserTextByColor | 获取光标对象 |
| `setCharFormat(fmt)` | QTextCursor | mInserTextByColor | 设置文字格式 |
| `insertText(str)` | QTextCursor | mInserTextByColor | 插入文字 |
| `setForeground(brush)` | QTextCharFormat | mInserTextByColor | 设置文字颜色 |
| `toUtf8()` | QString | on_btnSend_clicked | 转 UTF-8 字节数组 |
| `toInt()` | QString | on_btnConnect_clicked | 字符串转整数 |
| `setEnabled(bool)` | QWidget | 多处 | 控制控件可用/禁用 |
| `setLayout(layout)` | QWidget | 构造函数 | 设置布局管理器 |
| `qDebug()` | Qt 全局 | onError | 调试输出 |
