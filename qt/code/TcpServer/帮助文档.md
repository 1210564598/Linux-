### 构造函数 Widget::Widget()

```cpp
Widget::Widget(QWidget *parent)
    : QWidget(parent)
    , ui(new Ui::Widget)
{
    ui->setupUi(this);                       // ①
    this->setLayout(ui->verticalLayout);     // ②

    ui->btndiscon->setEnabled(false);        // ③
    ui->btnSend->setEnabled(false);

    client = new QTcpSocket(this);           // ④
    connect(client, SIGNAL(readyRead()),
            this, SLOT(mRead_Data_From_Server()));  // ⑤
}
```

| 编号 | 函数/技术 | 说明 |
|:----:|-----------|------|
| ① | `ui->setupUi(this)` | 由 UIC 工具从 widget.ui 自动生成的函数。在当前 Widget 上创建所有子控件（文本编辑框、按钮、标签、布局等），建立父子关系和布局 |
| ② | `this->setLayout(ui->verticalLayout)` | 将 .ui 文件中定义的顶层垂直布局设置为本 Widget 的布局管理器。setupUi 有时不会自动设置顶层 layout，需要手动调用 |
| ③ | `QPushButton::setEnabled(false)` | 设置按钮为禁用状态（灰色、不可点击）。初始状态下"断开"和"发送"按钮禁用，因为没有活动连接 |
| ④ | `new QTcpSocket(this)` | **创建 TCP 套接字**。`this` 作为父对象传入，利用 Qt 对象树机制——当 Widget 销毁时，该套接字自动被删除，无需手动 delete |
| ⑤ | `connect(client, SIGNAL(readyRead()), ...)` | **旧式信号槽连接**（基于字符串）。当服务器发来数据、套接字准备好读取时，自动调用 `mRead_Data_From_Server()` 槽函数 |

### 连接按钮槽 on_btnConnect_clicked()

```cpp
void Widget::on_btnConnect_clicked()
{
    client->connectToHost(                  // ①
        ui->lineEditIPAddr->text(),         // ②
        ui->lineEditPort->text().toInt());  // ③

    timer = new QTimer(this);               // ④
    timer->setSingleShot(true);             // ⑤
    timer->setInterval(5000);               // ⑥

    connect(timer, SIGNAL(timeout()),
            this, SLOT(onTimeOUt()));       // ⑦
    connect(client, SIGNAL(connected()),
            this, SLOT(onConnected()));      // ⑧
    connect(client, SIGNAL(error(QAbstractSocket::SocketError)),
            this, SLOT(onError(QAbstractSocket::SocketError)));  // ⑨

    this->setEnabled(false);                // ⑩
    timer->start();                         // ⑪
}
```

| 编号 | 函数/技术 | 说明 |
|:----:|-----------|------|
| ① | `QTcpSocket::connectToHost(host, port)` | **异步连接服务器**。第一个参数 `host` 可以是 IP 字符串或域名（内部会自动 DNS 解析）。调用后立即返回，连接结果通过 `connected` 或 `error` 信号通知 |
| ② | `QLineEdit::text()` | 获取输入框中的文本，返回 `QString` |
| ③ | `QString::toInt()` | 将字符串转换为 int 类型（端口号） |
| ④ | `new QTimer(this)` | **创建定时器**，以 `this` 为父对象 |
| ⑤ | `QTimer::setSingleShot(true)` | **设置为单次触发模式**。为 `true` 时定时器只触发一次就停止；为 `false`（默认）会周期性重复触发 |
| ⑥ | `QTimer::setInterval(5000)` | 设置超时间隔为 5000 毫秒 = 5 秒 |
| ⑦ | `connect(timer, SIGNAL(timeout()), ...)` | 连接定时器的 `timeout()` 信号到 `onTimeOUt` 槽，5 秒后若未取消则触发 |
| ⑧ | `connect(client, SIGNAL(connected()), ...)` | 连接套接字的 `connected` 信号——TCP 连接建立成功时触发 |
| ⑨ | `connect(client, SIGNAL(error(...)), ...)` | 连接套接字的 `error` 信号——连接失败时触发，参数是错误类型枚举 |
| ⑩ | `this->setEnabled(false)` | **禁用整个窗口**。连接过程中防止用户误操作（修改 IP、重复点击等），这是简易的防抖策略 |
| ⑪ | `QTimer::start()` | 启动定时器开始计时 |

**技术要点：**
- `connectToHost()` 是异步调用，不会阻塞 UI 线程
- 连接结果有三种路径：成功 → `connected()` / 失败 → `error()` / 超时 → `timeout()`
- 每次点击"连接"都会 `new QTimer`，旧的 timer 指针丢失（轻微内存泄漏）。修复方法：在 new 之前 `if(timer) delete timer`

### 接收数据槽 mRead_Data_From_Server()

```cpp
void Widget::mRead_Data_From_Server()
{
    ui->textEditRev->moveCursor(QTextCursor::End);   // ①
    ui->textEditRev->ensureCursorVisible();           // ②
    mInserTextByColor(Qt::black, client->readAll());  // ③
}
```

| 编号 | 函数/技术 | 说明 |
|:----:|-----------|------|
| ① | `QTextEdit::moveCursor(QTextCursor::End)` | 将文本光标移动到文档末尾，确保新内容追加在最后 |
| ② | `QTextEdit::ensureCursorVisible()` | 滚动视图保证光标可见，实现自动滚动到底部的效果 |
| ③ | `QTcpSocket::readAll()` | **读取套接字缓冲区中的全部数据**，返回 `QByteArray`。读取后缓冲区被清空 |

**技术要点：**
- `readyRead()` 信号可能分多次触发（数据分批到达），也可能一次触发包含多条消息
- `readAll()` 一次性读出当前缓冲区所有内容，简单高效
- 基于信号驱动（event-driven），不需要轮询

### 发送数据槽 on_btnSend_clicked()

```cpp
void Widget::on_btnSend_clicked()
{
    QByteArray sendData = ui->textEditSend->toPlainText().toUtf8();  // ①
    client->write(sendData);                                          // ②
    mInserTextByColor(Qt::red, sendData);                             // ③
}
```

| 编号 | 函数/技术 | 说明 |
|:----:|-----------|------|
| ① | `QTextEdit::toPlainText()` | 获取文本编辑框中的纯文本内容，返回 `QString` |
| ① | `QString::toUtf8()` | 将 `QString` 转换为 UTF-8 编码的 `QByteArray`。数组末尾自动包含 `\0` |
| ② | `QIODevice::write(QByteArray)` | **向套接字写入数据**（QTcpSocket 继承自 QIODevice）。数据被放入发送缓冲区，Qt 异步发送 |
| ③ | `mInserTextByColor(Qt::red, ...)` | 自定义辅助函数，以红色将发送内容回显到接收区 |

**技术要点：**
- 使用 UTF-8 编码可以支持中文和英文混合文本
- `write()` 是非阻塞的，数据先写入内部缓冲区，Qt 在事件循环中异步发送
- 红色回显让用户区分"发出的消息"和"收到的消息"

### 断开连接槽 on_btndiscon_clicked()

```cpp
void Widget::on_btndiscon_clicked()
{
    client->disconnectFromHost();          // ①
    client->close();                       // ②
    ui->textEditRev->append("中止连接！");  // ③

    ui->btnConnect->setEnabled(true);      // ④
    ui->lineEditPort->setEnabled(true);
    ui->lineEditIPAddr->setEnabled(true);
    ui->btndiscon->setEnabled(false);
    ui->btnSend->setEnabled(false);
}
```

| 编号 | 函数/技术 | 说明 |
|:----:|-----------|------|
| ① | `QTcpSocket::disconnectFromHost()` | **优雅断开连接**。发送 FIN 包，等待服务器确认后再完全关闭。适合正常断开 |
| ② | `QTcpSocket::close()` | **立即关闭套接字**。强制关闭 IO 设备，释放文件描述符 |
| ③ | `QTextEdit::append(QString)` | 在文本编辑框末尾追加一行文字并自动换行 |
| ④ | `QWidget::setEnabled(bool)` | 控制控件是否可交互，用于恢复/锁定 UI 状态 |

**技术要点：**
- `disconnectFromHost()` + `close()` 是标准的优雅关闭流程
- 逐一恢复按钮状态而不是简单 `setEnabled(true)` 整窗启用——因为需要"选择性恢复"特定控件

### 连接成功槽 onConnected()

```cpp
void Widget::onConnected()
{
    timer->stop();                         // ①
    this->setEnabled(true);                // ②
    ui->textEditRev->append("连接成功！");

    ui->btnConnect->setEnabled(false);     // ③
    ui->lineEditPort->setEnabled(false);
    ui->lineEditIPAddr->setEnabled(false);
    ui->btndiscon->setEnabled(true);
    ui->btnSend->setEnabled(true);
}
```

| 编号 | 函数/技术 | 说明 |
|:----:|-----------|------|
| ① | `QTimer::stop()` | **停止定时器**。连接成功后取消超时计时，防止 `onTimeOUt()` 误触发 |
| ② | `this->setEnabled(true)` | 恢复整窗操作（从 `on_btnConnect_clicked` 的禁用状态恢复） |
| ③ | 选择性启用/禁用 | 连接后：IP/端口输入框和连接按钮锁定，断开和发送按钮解锁 |

### 错误处理槽 onError()

```cpp
void Widget::onError(QAbstractSocket::SocketError error)
{
    qDebug() << "连接错误：" << error;                              // ①
    ui->textEditRev->insertPlainText(
        "连接出问题啦：" + client->errorString());                  // ②
    this->setEnabled(true);                                        // ③
    on_btndiscon_clicked();                                        // ④
}
```

| 编号 | 函数/技术 | 说明 |
|:----:|-----------|------|
| ① | `qDebug()` | Qt 调试输出流，类似 `std::cout`，在 Release 模式下可通过宏定义禁用 |
| ② | `QAbstractSocket::errorString()` | 获取最后一次错误的**可读描述字符串**，如 "Connection refused"、"Host not found" |
| ② | `QTextEdit::insertPlainText(QString)` | 在光标当前位置插入纯文本（与 `append` 不同，`append` 会自动换行） |
| ④ | `on_btndiscon_clicked()` | **复用断开逻辑**清理状态，避免重复代码 |

**技术要点：**
- `error` 信号参数 `QAbstractSocket::SocketError` 是枚举类型，包含 `ConnectionRefusedError`、`HostNotFoundError`、`SocketTimeoutError` 等
- `errorString()` 比枚举值更便于用户理解
- 在错误处理中复用 `on_btndiscon_clicked()` 保证 UI 状态一致性

### 连接超时槽 onTimeOUt()

```cpp
void Widget::onTimeOUt()
{
    ui->textEditRev->insertPlainText("连接超时");
    client->abort();                     // ①
    this->setEnabled(true);
}
```

| 编号 | 函数/技术 | 说明 |
|:----:|-----------|------|
| ① | `QTcpSocket::abort()` | **强制中止连接并重置套接字**。与 `close()` 不同，`abort()` 立即关闭并丢弃所有待发送数据，适合超时场景 |

**技术要点：**
- `abort()` vs `disconnectFromHost()` + `close()`：
  - `abort()` = 立即中止，不等待服务器确认，适合超时
  - `disconnectFromHost()` + `close()` = 优雅关闭，适合正常断开
- Qt 的 `connectToHost()` 默认使用操作系统超时（20-120秒），本项目用 QTimer 自定义 5 秒超时

### 彩色文字插入 mInserTextByColor()

```cpp
void Widget::mInserTextByColor(Qt::GlobalColor color, QString str)
{
    QTextCursor cursor = ui->textEditRev->textCursor();    // ①
    QTextCharFormat format;                                // ②

    format.setForeground(QBrush(QColor(color)));           // ③
    cursor.setCharFormat(format);                          // ④

    cursor.insertText(str);                                // ⑤
}
```

| 编号 | 函数/技术 | 说明 |
|:----:|-----------|------|
| ① | `QTextEdit::textCursor()` | 获取当前文本光标对象的副本。光标记录了位置、选中范围、字符格式等 |
| ② | `QTextCharFormat` | 字符格式描述类，包含字体、颜色、大小等信息 |
| ③ | `QTextCharFormat::setForeground(QBrush)` | 设置前景色（文字颜色）。`QBrush(QColor(Qt::red))` 创建一个红色画刷 |
| ④ | `QTextCursor::setCharFormat(format)` | 将字符格式应用于光标位置的文本。后续 `insertText` 会沿用此格式 |
| ⑤ | `QTextCursor::insertText(str)` | 在光标位置插入文本。由于光标在末尾且格式已设为红色/黑色，能实现彩色追加 |

**技术要点：**
- `QTextEdit` 支持富文本（类似 HTML），不同位置的文字可以有不同格式
- `QTextCursor` 是操控文本编辑框内部内容的 API，比直接操作 QString 更灵活
- `Qt::GlobalColor` 是 Qt 预定义的颜色枚举，`Qt::black`=0, `Qt::red`=3

## 信号槽连接总结

### 自动连接（Qt 命名约定）

不需要写 `connect()`，Qt 通过 `on_<控件名>_<信号名>()` 命名自动匹配：

| 控件名 | 信号 | 槽函数 |
|--------|------|--------|
| btnConnect | clicked() | on_btnConnect_clicked() |
| btnSend | clicked() | on_btnSend_clicked() |
| btndiscon | clicked() | on_btndiscon_clicked() |

### 手动连接（代码中的 connect）

| 源对象 | 信号 | 槽函数 | 连接时机 |
|--------|------|--------|----------|
| client | readyRead() | mRead_Data_From_Server() | 构造函数（一次） |
| client | connected() | onConnected() | 每次点击连接 |
| client | error() | onError() | 每次点击连接 |
| timer | timeout() | onTimeOUt() | 每次点击连接 |

## 关键技术点

### 1. Qt 对象树与内存管理

`new QTcpSocket(this)` 将套接字注册为 Widget 的子对象。当 Widget 被销毁时，Qt 从子对象列表中找到 QTcpSocket 并自动 `delete`，无需手动释放。

### 2. 异步网络通信

Qt 的网络 API 都是异步的——`connectToHost()` 调用后立即返回，连接结果通过信号通知。UI 线程不会被阻塞，窗口保持响应。

### 3. 自定义连接超时

Qt 默认不使用 `connectToHost()` 内置超时（或等 OS 默认 20-120 秒）。本项目用 QTimer + abort() 组合实现 5 秒自定义超时。

### 4. 防重复操作

`this->setEnabled(false)` 禁用整个窗口——简单但有效。QWidget 的 `setEnabled` 会递归禁用所有子控件。

### 5. 套接字生命周期

```
未连接 ──connectToHost()──► 连接中 ──connected()──► 已连接 ──disconnectFromHost()──► 未连接
                              │                        │
                              ├── error()              └── close()
                              └── timeout() + abort()
```
