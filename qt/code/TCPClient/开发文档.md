# TCPClient 开发文档

## 项目概述

TCPClient 是一个基于 Qt 5.12.9 的网络调试助手客户端程序。该项目提供了完整的图形用户界面，用于与远程 TCP 服务器建立连接、发送数据和接收响应。

├── TCPClient.pro           # qmake 项目文件
├── widget.h                # Widget 类头文件

├── widget.ui               # Qt Designer 界面文件

## 类设计

### Widget 类

继承自 `QWidget`，是应用程序唯一的用户自定义类。通过 `Ui::Widget`（由 UIC 从 `widget.ui` 自动生成）管理所有子控件。

```
QWidget
  └── Widget
        └── Ui::Widget (自动生成)
              ├── QTextEdit      textEdit      (接收消息显示区)
              ├── QLineEdit      lineEdit      (服务器IP输入)
              ├── QLineEdit      lineEdit_2    (服务器端口输入)
              ├── QPushButton    btnConnect    (连接按钮)
              ├── QPushButton    btndiscon     (断开按钮)
              ├── QTextEdit      textEdit_2    (消息输入区)
              └── QPushButton    btnSend       (发送按钮)
```

**Widget 类声明（widget.h）：**

```cpp
class Widget : public QWidget
{
    Q_OBJECT

public:
    Widget(QWidget *parent = nullptr);
    ~Widget();

private:
    Ui::Widget *ui;
};
```

## 实现指南

### 1. 添加网络模块

在 `TCPClient.pro` 的 `QT +=` 行添加 `network`：

```qmake
QT += core gui widgets network
```

### 2. 在 Widget 类中添加 QTcpSocket

在 `widget.h` 中添加：

```cpp
#include <QTcpSocket>

class Widget : public QWidget
{
    Q_OBJECT

public:
    Widget(QWidget *parent = nullptr);
    ~Widget();

private slots:
    void on_btnConnect_clicked();
    void on_btndiscon_clicked();
    void on_btnSend_clicked();
    void onConnected();
    void onDisconnected();
    void onReadyRead();
    void onError(QAbstractSocket::SocketError socketError);

private:
    Ui::Widget *ui;
    QTcpSocket *tcpSocket;
    void updateConnectionState(bool connected);
};
```

### 3. 实现网络逻辑

在 `widget.cpp` 中实现：

```cpp
Widget::Widget(QWidget *parent)
    : QWidget(parent)
    , ui(new Ui::Widget)
{
    ui->setupUi(this);
    
    tcpSocket = new QTcpSocket(this);
    
    connect(tcpSocket, &QTcpSocket::connected, this, &Widget::onConnected);
    connect(tcpSocket, &QTcpSocket::disconnected, this, &Widget::onDisconnected);
    connect(tcpSocket, &QTcpSocket::readyRead, this, &Widget::onReadyRead);
    connect(tcpSocket, 
            QOverload<QAbstractSocket::SocketError>::of(&QAbstractSocket::error),
            this, &Widget::onError);
    
    updateConnectionState(false);
}

void Widget::on_btnConnect_clicked()
{
    QString ip = ui->lineEdit->text();
    quint16 port = ui->lineEdit_2->text().toUShort();
    tcpSocket->connectToHost(ip, port);
}

void Widget::on_btndiscon_clicked()
{
    tcpSocket->disconnectFromHost();
}

void Widget::on_btnSend_clicked()
{
    QString data = ui->textEdit_2->toPlainText();
    tcpSocket->write(data.toUtf8());
}

void Widget::onConnected()
{
    ui->textEdit->append("已连接到服务器");
    updateConnectionState(true);
}

void Widget::onDisconnected()
{
    ui->textEdit->append("已断开连接");
    updateConnectionState(false);
}

void Widget::onReadyRead()
{
    QByteArray data = tcpSocket->readAll();
    ui->textEdit->append("收到: " + QString::fromUtf8(data));
}

void Widget::onError(QAbstractSocket::SocketError socketError)
{
    ui->textEdit->append("错误: " + tcpSocket->errorString());
}

void Widget::updateConnectionState(bool connected)
{
    ui->btnConnect->setEnabled(!connected);
    ui->btndiscon->setEnabled(connected);
    ui->lineEdit->setEnabled(!connected);
    ui->lineEdit_2->setEnabled(!connected);
}
```

### 4. 信号槽连接方式说明

Qt 支持两种信号槽连接方式：

**方式一：手动连接（推荐用于复杂逻辑）**
```cpp
connect(ui->btnConnect, &QPushButton::clicked, this, &Widget::on_btnConnect_clicked);
```

**方式二：自动连接（按命名约定）**
如果槽函数命名为 `on_<widgetName>_<signalName>` 格式，可在构造函数中调用：
```cpp
// 在 ui->setupUi(this) 之后无法自动连接，需显式调用
// 或使用 QMetaObject::connectSlotsByName(this);
```

注意：使用 `QMetaObject::connectSlotsByName(this)` 时，槽函数命名必须严格遵循 `on_<对象名>_<信号名>` 格式。

## 开发注意事项

1. **对象名称一致性**：`widget.ui` 中定义的控件对象名（如 `btnConnect`）必须与代码中引用的一致
2. **编码格式**：项目使用 UTF-8 编码，确保中文文本正确显示
3. **网络权限**：Qt 网络操作不需要特殊权限，但在某些平台上可能需要配置防火墙规则
4. **线程安全**：QTcpSocket 的所有操作应在创建它的线程中执行
5. **内存管理**：QTcpSocket 作为 QObject 的子对象，由 Qt 父子关系自动管理内存
