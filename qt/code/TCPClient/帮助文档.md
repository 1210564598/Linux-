# TCPClient 帮助文档

## 产品简介

TCPClient（网络调试助手客户端）是一款基于 Qt 开发的 TCP 网络通信调试工具。它提供了简洁直观的图形界面，帮助开发者快速建立 TCP 连接、发送测试数据和查看服务器响应，是网络程序开发与调试的得力助手。

## 系统要求

| 项目 | 最低要求 |
|------|----------|
| 操作系统 | Windows 7 及以上 |
| 处理器 | 1 GHz 及以上 |
| 内存 | 512 MB 及以上 |
| 磁盘空间 | 50 MB 可用空间 |
| 依赖 | Qt 5.12.9 运行时库 |

## 安装说明

### 方式一：直接运行（推荐）

如果您已安装 Qt 5.12.9 运行时环境，直接双击编译生成的可执行文件即可运行。

### 方式二：使用 Qt Creator 编译运行

1. 安装 Qt 5.12.9（MinGW 32-bit）
2. 打开 Qt Creator，加载 `TCPClient.pro` 项目文件
3. 点击运行按钮（Ctrl+R）

## 使用指南

### 基本操作流程

**步骤一：启动服务器**

在使用客户端之前，请确保目标 TCP 服务器已启动并在监听端口。可以使用配套的 TcpServer 程序或其他 TCP 服务器。

**步骤二：配置连接参数**

1. 在"服务端IP"输入框中输入服务器的 IP 地址
   - 本地测试：输入 `127.0.0.1`
   - 局域网通信：输入服务器的局域网 IP（如 `192.168.1.100`）
2. 在"服务端端口"输入框中输入服务器的端口号
   - 常用测试端口：`8080`、`8888`、`9000`

**步骤三：建立连接**

点击"连接"按钮，程序会尝试连接到指定的服务器。连接成功后，接收消息显示区会显示"已连接到服务器"。

**步骤四：发送消息**

1. 在消息输入区中输入要发送的内容
2. 点击"发送"按钮，消息将通过 TCP 连接发送给服务器
3. 消息支持中文和英文字符（UTF-8 编码）

**步骤五：接收消息**

当服务器发送消息时，接收消息显示区会自动显示收到的内容，格式为"收到: [消息内容]"。

**步骤六：断开连接**

点击"断开"按钮可断开与服务器的连接。断开后接收消息显示区会显示"已断开连接"。

### 连接状态说明

| 状态 | 连接按钮 | 断开按钮 | IP/端口输入 | 说明 |
|------|:--------:|:--------:|:----------:|------|
| 未连接 | 可用 | 禁用 | 可用 | 可以输入参数并发起新连接 |
| 已连接 | 禁用 | 可用 | 禁用 | 连接已建立，可以发送/接收消息 |

### 典型使用场景

**场景一：网络程序调试**

当您正在开发一个 TCP 服务器程序时，可以使用本客户端向服务器发送测试数据，验证服务器的响应是否正确。

**场景二：协议测试**

向服务器发送特定的协议指令，观察服务器返回的数据格式和内容，用于验证网络协议的实现。

**场景三：通信验证**

在局域网中验证两台计算机之间的 TCP 通信是否正常，排查网络连接问题。

## 常见问题

### Q1：点击"连接"后没有反应？

可能的原因及解决方法：
1. 服务器未启动 —— 请先启动目标 TCP 服务器
2. IP 地址错误 —— 检查输入的 IP 地址是否正确
3. 端口号错误 —— 确认端口号与服务器监听的端口一致
4. 防火墙阻止 —— 检查防火墙设置，允许程序通过

### Q2：连接成功但发送消息失败？

检查以下几点：
1. 确认连接状态是否正常（连接按钮应为禁用状态）
2. 检查消息输入区是否有内容
3. 查看接收消息显示区是否有错误提示

### Q3：收到乱码？

本程序使用 UTF-8 编码进行通信。请确保服务器端也使用 UTF-8 编码发送和接收数据。

### Q4：如何与 TcpServer 配合使用？

1. 先启动 TcpServer 程序，点击"监听"按钮
2. 启动 TCPClient 程序，输入 TcpServer 上显示的 IP 地址和端口号
3. 点击"连接"按钮
4. 双方即可通过消息输入区和发送按钮进行通信

## 注意事项

1. 请勿同时向同一服务器发起多个连接（除非服务器支持），可能导致不可预期的行为
2. 发送大量数据时请分批发送，避免网络拥塞
3. 建议在局域网环境下使用，公网通信请确保网络安全
4. 程序不会自动保存通信记录，如需保存请手动复制粘贴
