# 串口调试助手 —— 功能实现对照学习文档

## 项目概览

本文档按照代码结构，分步骤说明串口调试助手从 UI 到完整功能实现的每一部分逻辑，方便你对照学习。

**文件结构：**
```
Serial/                          ← 你原始的项目（只有 UI）
Serial/full_version/             ← 补全后的完整版
  ├── Serial_full.pro            ← 项目文件（新增了 serialport 模块）
  ├── main.cpp                   ← 程序入口（未修改）
  ├── widget.h                   ← 头文件（新增大量声明）
  ├── widget.cpp                 ← 实现文件（全部功能逻辑）
  ├── widget.ui                  ← UI 文件（未修改）
  ├── res.qrc                    ← 资源文件（未修改）
  └── mianicon.png              ← 图标（未修改）
```

---

## 第一步：修改项目配置文件 `.pro`

**位置：** `full_version/Serial_full.pro`

**关键修改：** 将 `QT += core gui` 改为 `QT += core gui serialport`

**原因：** Qt 的串口功能在 `QtSerialPort` 模块中，与 GUI 模块是独立的。如果不加 `serialport`，编译时找不到 `<QSerialPort>` 头文件。

---

## 第二步：补全头文件 `widget.h`

**对比学习要点：**

| 原始代码 | 补全后新增 |
|---------|-----------|
| 只包含 `<QWidget>` | 新增 `<QSerialPort>` `<QSerialPortInfo>` `<QTimer>` 等 |
| 只有构造/析构 | 新增 20+ 个槽函数声明 |
| 只有 `Ui::Widget *ui` | 新增 `m_serial` `m_sendTimer` `m_loopTimer` 等成员变量 |

**核心成员变量说明：**

```cpp
QSerialPort *m_serial;       // 串口对象——所有串口操作都通过它
QTimer *m_sendTimer;          // 定时发送计时器——按用户设定的间隔自动发送
QTimer *m_loopTimer;          // 循环发送计时器——用于多文本面板的循环发送
int m_receivedCount;          // 累计接收字节数（显示在底部状态栏）
int m_sentCount;              // 累计发送字节数
bool m_isSerialOpen;          // 串口是否已打开的标志位
```

**槽函数的两种连接方式：**

1. **自动连接（`on_控件名_信号名`）**：Qt 会自动将 UI 中同名的控件信号连接到这些槽，不需要写 `connect`。例如 `on_pushButton_Closeser_clicked()` 会自动连接"打开/关闭串口"按钮的点击信号。
2. **手动连接（`QObject::connect`）**：用于非 UI 控件的情况，比如串口数据到达信号、定时器信号。在 `initConnections()` 中统一处理。

## 第三步：构造函数与初始化（widget.cpp 第一部分）

**构造函数执行流程：**

```
Widget::Widget()
  │
  ├─ initSerialPort()       // new QSerialPort(this)
  ├─ initComboBoxes()       // 填充串口参数下拉框
  │    ├─ refreshPortList() // 扫描系统可用串口
  │    ├─ 添加波特率: 1200~115200（默认9600）
  │    ├─ 添加数据位: 5~8（默认8）
  │    ├─ 添加校验位: None/Even/Odd/Mark/Space
  │    ├─ 添加停止位: 1/1.5/2
  │    └─ 添加流控: None/RTS-CTS/XON-XOFF
  │
  └─ initConnections()      // 连接所有信号槽
       ├─ m_serial::readyRead → onReadyRead  (有数据到达)
       ├─ m_sendTimer::timeout → onTimedSend (定时发送)
       ├─ m_loopTimer::timeout → onLoopSend  (循环发送)
       ├─ m_serial::errorOccurred → 错误弹窗
       └─ lineEditRate::textChanged → 更新定时器间隔
```

**关键知识点：`addItem(text, userData)`**

每个下拉框选项在添加时携带了一个 `userData`（用枚举值），这样读取时不需要做字符串比较：
```cpp
ui->comboBox_3->addItem("9600", QSerialPort::Baud9600);
// 读取时直接用：
int baudRate = ui->comboBox_3->currentData().toInt();
```

## 第四步：串口打开/关闭控制（widget.cpp 第三部分）

**逻辑流程：**

```
点击"打开串口"按钮
  │
  ├─ 当前已打开? ──是──→ 关闭串口
  │                      ├─ stop 所有计时器
  │                      ├─ m_serial->close()
  │                      ├─ 按钮文字 → "打开串口"
  │                      └─ 解锁所有下拉框
  │
  └─ 当前未打开? ──是──→ 打开串口
                          ├─ 检查是否有可用串口
                          ├─ 依次设置：端口名、波特率、数据位、校验位、停止位、流控
                          ├─ m_serial->open(ReadWrite)
                          ├─ 成功: 按钮文字 → "关闭串口", 锁定下拉框
                          └─ 失败: 弹错误框
```

**设计细节：** 打开串口时锁定参数下拉框，关闭时解锁——防止串口已打开时用户更改参数导致混乱。

## 第五步：数据发送（widget.cpp 第四部分）

这是功能最丰富的一块，包含 4 种发送方式：

### 5.1 普通发送

```cpp
void Widget::sendData()
```
流程：获取文本框内容 → 判断HEX/文本模式编码 → 判断是否追加新行 → 写入串口 → 更新计数

### 5.2 定时发送

由 `m_sendTimer` 驱动，用户勾选"定时发送"并在 `lineEditRate` 输入间隔（ms），计时器每隔该时间自动调用 `sendData()`。

### 5.3 多文本快捷发送（9个按钮）

每个按钮对应一行多文本输入框，点击即发送该行内容。

### 5.4 循环发送

遍历多文本面板的 9 行，勾选的且非空的就发送。由 `m_loopTimer` 按 spinBox 设定的间隔重复执行。

**HEX 发送的重要实现：**

`hexStringToBytes()` 函数将用户输入的 `"AA BB CC"` 转为真正的字节数组：
```cpp
QString cleaned = hexStr.simplified().remove(' '); // 去空格
for (int i = 0; i < cleaned.length(); i += 2) {
    QString byteStr = cleaned.mid(i, 2);  // 每2字符一个字节
    quint8 byte = byteStr.toUInt(&ok, 16); // 16进制转数字
    result.append(static_cast<char>(byte));
}
```

## 第六步：数据接收（widget.cpp 第五部分）

### 核心回调：`onReadyRead()`

```cpp
void Widget::onReadyRead()
{
    QByteArray data = m_serial->readAll();    // 读取所有到达的数据
    m_receivedCount += data.size();            // 累计计数

    // 根据复选框决定显示格式
    if (ui->checkBox_HEK->isChecked())
        displayText = bytesToHexString(data);  // HEX: "41 42 43"
    else
        displayText = QString::fromUtf8(data); // 文本: "ABC"

    if (ui->checkBox_TIME->isChecked())
        displayText = "[13:14:15.678] " + displayText;  // 加时间戳

    if (ui->checkBox_ZDHH->isChecked())
        displayText += "\n";                    // 自动换行

    ui->textEditRev->insertPlainText(displayText);  // 追加显示
    // 滚动到底部...
}
```

**关键区分：`insertPlainText` vs `append`**

- `append()` 始终会在内容末尾加 `\n` 换行
- `insertPlainText()` 不会自动换行，需要手动控制

这里用 `insertPlainText` 以便配合"自动换行"复选框灵活控制。

### 辅助功能

- **清空接收区**：清除文本框 + 重置计数
- **保存接收**：用 `QFileDialog` 选择保存路径，将 `textEditRev.toPlainText()` 写入文件

## 编译与运行

1. 在 Qt Creator 中打开 `Serial_full.pro`
2. 确保你的 Qt 安装了 `Qt Serial Port` 组件
3. 点击构建并运行

## 进阶学习建议

1. **无串口硬件时如何测试？** 安装虚拟串口工具（如 com0com / VSPD），创建一对虚拟串口，在程序中选择一个发送，用另一个串口助手查看接收。

2. **扩展方向：**
   - 添加更多波特率（如 230400, 460800, 921600）
   - 添加 DTR/RTS 引脚控制
   - 支持 Modbus 协议解析
   - 添加波形/图表显示（用 QChart）
   - 支持 TCP/串口透传模式
